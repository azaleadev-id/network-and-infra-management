# Network & Infrastructure Management

This repository contains a PHP and React Native portfolio project for managing RT/RW Net style network operations. It includes dashboard views, tenant/admin access control, MikroTik integration, PPPoE and Hotspot workflows, infrastructure topology mapping, billing status, payment handling, and a companion mobile application.

> This repository is a sanitized portfolio version of the project. Production credentials, infrastructure details, customer data, and other sensitive configuration are intentionally excluded or replaced with example values.

## Project Overview

The web application is a multi-tenant network management panel. It centralizes customer records, router connectivity, network node mapping, user status monitoring, billing, isolation workflows, notification settings, and operational dashboards. The mobile app provides a React Native foundation for mobile access to the same service domain.

## Key Features

- Multi-tenant admin, owner, operator, viewer, cashier, collector, and staff access paths.
- Dashboard APIs for network summaries, PPPoE status, infrastructure status, and billing metrics.
- MikroTik RouterOS integration through socket and REST-style configuration paths.
- PPPoE and Hotspot user management, including active session lookup and remote address handling.
- Billing records with due dates, payment status, receipt printing, and automatic isolation support.
- Infrastructure mapping for servers, ODC, ODP, user nodes, topology relations, and map-based location picking.
- Tenant settings for router credentials, app naming, traffic interface, backup settings, and bridge API keys.
- Mobile API endpoints for authentication, dashboard, billing, profile, employee, tenant linking, and client lookup.
- Database schema and synchronization migration scripts for local development.

## Architecture

- `index.php` is the main web entry point and routes authenticated views.
- `api/` contains JSON endpoints for web, mobile, cron, billing, users, topology, MikroTik, and settings workflows.
- `config/` centralizes environment loading, authentication/session handling, database connection, MikroTik clients, backup helpers, bridge helpers, and RouterOS API support.
- `models/` contains domain models for users, routers, locations, billing, alerts, audit logs, notifications, and network relations.
- `views/` contains the PHP dashboard screens and shared sidebar partial.
- `public/` contains CSS, browser JavaScript, receipt printing logic, map helpers, and image assets.
- `database/` contains the sanitized schema dump and schema synchronization script.
- `mobile-app/` contains the React Native mobile project.
- `storage/` is reserved for runtime cache, sessions, logs, cookies, uploaded photos, and local settings. Runtime contents are ignored from Git.

## Tech Stack

## Installation / Development Setup

1. Clone the repository.
2. Copy `.env.example` to `.env`.
3. Create a MySQL or MariaDB database named `rt_rw_net`.
4. Import `database/rt_rw_net.sql`.
5. If needed, run `database/2026_05_17_sync_existing_database_schema.sql` against an older local database.
6. Configure database credentials, MikroTik connection values, map keys, Google OAuth client IDs, and cron tokens in `.env`.
7. Serve the project through Apache/XAMPP or another PHP-capable web server.
8. Ensure `storage/cache`, `storage/logs`, and `storage/sessions` are writable by PHP.

For the mobile app:

```bash
cd mobile-app
npm install
npm test
```

## Environment Configuration

Required configuration is documented in `.env.example`. Sensitive values such as database passwords, router credentials, API keys, OAuth client IDs, cron tokens, bridge tokens, and mobile lookup tokens must be supplied locally and must not be committed.

Runtime app settings that can be generated by the application are stored in `storage/app_settings.json`. Use `storage/app_settings.example.json` as a safe reference.

## Security / Public Repository Notice

- `.env` is ignored and should remain local only.
- Runtime storage for sessions, cache, cookies, logs, and uploaded user files is ignored.
- SQL files in this repository are sanitized for portfolio use and omit production data rows.
- Router credentials, infrastructure hostnames, customer records, cookies, sessions, and production cache snapshots are excluded from the public repository.
