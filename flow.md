## Keterangan

- Flow web menggunakan session PHP.
- Flow mobile menggunakan bearer token.
- Semua data dibatasi berdasarkan tenant yang diizinkan.
- Pembayaran lunas dapat membuka isolir MikroTik secara otomatis.
- Cron isolir dan monitoring menyimpan hasilnya ke database.
- Dashboard membaca kembali status billing, jaringan, MikroTik, dan alert.
